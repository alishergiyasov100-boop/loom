# Yura

Модель 2D-анимации, которая работает штрихами, а не пикселями.

Кадр разбирается на линии, линии прослеживаются сквозь сцену,
и дальше модель учится их двигать. Линия не перерисовывается —
она переезжает, поэтому не дрожит.

## Что внутри

| файл | что делает |
|---|---|
| `tools/lines.py` | линия из кадра и утончение до пикселя, на numpy |
| `tools/vectorize.py` | скелет в штрихи, трассировка идёт сквозь развилки |
| `tools/track_np.py` | слежение за штрихами между кадрами |
| `tools/harvest.py` | видео в траектории |
| `tools/net.py` | небольшая сеть на numpy |
| `tools/render.py` | штрихи обратно в картинку и видео |
| `app/` | холст: рисует штрихи вживую, как рука |
